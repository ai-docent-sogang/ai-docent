# AI 도슨트 지식 DB 구조 및 활용 가이드

## 1. DB 구축 목적

본 DB는 외국인 관람객을 대상으로 한국 미술 작품의 해설, 맞춤형 질의응답 및 해외 작품과의 비교 감상을 제공하기 위해 구축되었다. AI가 사전 학습 지식에만 의존하지 않고 작품별 지식과 비교 지식을 기반으로 정확하고 일관된 해설을 제공하는 데 목적이 있다.

| 파일 | 데이터 단위 | 규모 |
| --- | --- | --- |
| `artworks_1126_final_v2.csv` | 한국 작품 | 11행 × 18컬럼 |
| `comparisons_1126_final.csv` | 한국·해외 작품 비교쌍 | 21행 × 17컬럼 |

주요 지식과 초기 해설은 영어로, 출처 기록과 도슨트 운영 지침은 한국어로 작성하였다. 두 CSV는 UTF-8 BOM 형식이다.

## 2. DB 간 연결 구조

두 DB는 `artwork_id`로 연결된다. 작품 DB의 기본키는 `artwork_id`, 비교 작품 DB의 기본키는 `comparison_id`이며, 하나의 한국 작품에 여러 비교쌍이 연결되는 일대다(1:N) 관계이다. 예를 들어 `JS_INWANG`으로 비교 작품 DB를 조회하면 인왕제색도에 연결된 비교 후보를 얻을 수 있다. 작품명이나 작가명 대신 고유 ID로 조회하는 것을 권장한다.

## 3. 한국 작품 지식 DB (artworks)

### 3.1. 컬럼 구성

| 컬럼명 | 설명 |
| --- | --- |
| artwork_id | 한국 작품 고유 식별자 |
| title_ko | 한국어 작품명 |
| title_en | 영어 작품명 |
| artist | 작가 정보 |
| date | 제작 시기 |
| medium | 작품 재료 |
| designation | 국가유산 지정 정보 |
| collection_no | 소장품 번호 |
| official_url | 공식 소장품 페이지 URL |
| checked_at | 지식 검증 날짜 |
| verification_status | 지식 검증 상태 |
| key_facts | 작품별 핵심 지식 |
| source_note | 출처 및 근거 범위 |
| docent_guidelines | 작품별 해설 및 답변 생성 시 주의사항 |
| initial_description | 최초 작품 인식 시 제공할 영어 초기 해설 |
| image_license | 작품 이미지 이용 조건 |
| on_view_status | 현재 전시 여부 |
| unverified_facts | 검증되지 않은 지식 관리용 컬럼 |

### 3.2. key_facts: 작품별 핵심 지식

심화 해설 및 관람객 질의응답에 활용한다. 각 지식 단위는 ` | ` 구분자로 연결되며 다음 분류 태그를 포함한다.

| 태그 | 지식 유형 |
| --- | --- |
| [artist] | 작가의 생애, 화풍, 활동 및 미술사적 특징 |
| [features] | 소재, 구도, 색채, 표현 기법 및 시각적 특징 |
| [context] | 시대적·사회적·문화적 배경 |
| [interpretation] | 의미, 상징, 학술적 해석 및 감상 관점 |
| [provenance] | 소장 이력 및 전래 과정 |

모든 지식을 한 번에 나열하지 않고 질문과 관심사에 따라 선택적으로 활용한다. 작가 질문에는 [artist], 표현 기법에는 [features], 역사적 배경에는 [context]를 우선 활용하되, 필요한 경우 여러 유형을 함께 활용할 수 있다.

### 3.3. initial_description: 초기 작품 해설

최초 작품 인식 시 제공할 사전 작성 영어 해설이다. 작품명, 작가, 주요 시각적 특징 및 감상 포인트를 중심으로 구성하며 마지막에 개방형 질문을 포함한다. 초기 해설은 이 컬럼을 우선 활용하고 key_facts 전체를 매번 다시 요약할 필요는 없다. 이후 응답과 추가 질문에 따라 key_facts로 대화를 확장한다.

### 3.4. docent_guidelines: 작품별 도슨트 운영 지침

확정 사실과 학술적 추정의 구분, 작가 귀속 및 작품 식별, 제작 목적과 작가 의도의 과도한 단정 방지, 전문용어 설명, 역사·문화적 일반화 방지 등을 위한 지침이다. 관람객에게 직접 읽어주는 해설문이 아니라 답변 생성에 적용하는 제약사항이다. key_facts와 함께 참조하되 표현 방식과 해석 범위에서는 지침을 우선 적용한다.

## 4. 해외 비교 작품 지식 DB (comparisons)

### 4.1. 컬럼 구성

| 컬럼명 | 설명 |
| --- | --- |
| comparison_id | 비교쌍 고유 식별자 |
| artwork_id | 연결되는 한국 작품의 고유 식별자 |
| foreign_title | 해외 비교 작품명 |
| foreign_artist | 해외 작품 작가 정보 |
| foreign_date | 해외 작품 제작 시기 |
| foreign_collection | 해외 작품 소장처 및 식별 정보 |
| foreign_url | 해외 작품 공식 소장품 페이지 URL |
| checked_at | 지식 검증 날짜 |
| verification_status | 지식 검증 상태 |
| profile_tags | 맞춤형 비교 작품 추천에 활용할 태그 |
| angle | 핵심 비교 관점 및 선정 근거 |
| foreign_key_facts | 해외 작품 자체의 핵심 지식 |
| similarities | 두 작품의 공통점 |
| differences | 두 작품의 차이점 |
| source_note | 비교 지식 출처 및 근거 범위 |
| docent_guidelines | 비교 해설 및 질의응답 시 주의사항 |
| initial_comparison | 최초 비교 감상 시 제공할 영어 해설 |

### 4.2. profile_tags: 관람객 맞춤형 추천 태그

비교 작품의 국가, 지역, 미술 사조, 소재, 표현 기법, 감상 주제 등을 나타내는 영어 키워드이다. 세미콜론(`;`)으로 구분된다. 실제 태그의 예로 `france`, `post-impressionism`, `family`, `nature`, `ink-painting`, `woodblock-print` 등이 있다.

현재 서비스에서 관람객이 직접 선택하는 프로필 정보는 **국적과 연령대**뿐이다. 관심 분야나 선호 미술 양식은 별도로 입력받지 않으므로, AI가 초기 해설에 대한 응답, 후속 질문, 관람객이 주목한 소재 및 표현 기법 등 대화 내용을 기반으로 관심 태그를 동적으로 추론하도록 권장한다.

DB의 `profile_tags`는 비교 작품에 부여된 고정 태그이다. AI는 이를 수정하지 않고, 대화에서 추론한 관람객 관심 태그를 별도의 세션 정보(예: `visitor_interest_tags`)로 관리하여 매칭한다. 이 변수명은 구현 예시이며 실제 DB 컬럼이 아니다.

#### 추천 절차

1. 현재 작품의 `artwork_id`로 비교 후보를 제한한다.
2. 후보들의 `profile_tags`와 `angle`을 조회한다.
3. 관람객의 발언과 질문에서 관심사를 추론하고 후보에 존재하는 영어 태그로 정규화한다. 관심 근거가 부족하면 억지로 태그를 부여하지 않는다.
4. 명시적으로 표현된 관심사를 우선 고려하여 후보 태그와 매칭하고, `angle`을 통해 실제 비교 관점이 적합한지 판단한다.
5. 국적은 문화적 친숙성을 고려하는 보조 정보로, 연령대는 해설의 어휘와 난이도를 조정하는 참고 정보로 활용한다.
6. 대화가 이어지면서 새로운 관심사가 확인되면 관심 태그를 갱신한다. 추천할 작품은 해당 한국 작품에 연결된 후보 중에서만 선택한다.

#### 적용 예시

현재 작품이 이암의 「어미개와 강아지」인 경우:

| 관람객 발언 예시 | 추론 가능한 관심 태그 | 추천 후보 |
| --- | --- | --- |
| “I love the bond between the mother and her puppies.” | animals, dogs, motherhood | 우드리의 Hound and Her Puppies |
| “I'm curious about how ink captures the movement of puppies.” | puppies, ink-painting, brushwork | 로세쓰의 Puppies in the Snow |

위 사례는 추천 로직의 예시이며 실제 추천은 대화 맥락과 angle을 함께 고려한다. 단순 태그 일치 개수만으로 결정할 필요는 없다.

관심사가 아직 드러나지 않았다면 국적과 비교 관점의 적합성을 보조적으로 고려하거나 자연스러운 감상 질문으로 관심사를 파악할 수 있다. 국적이나 연령대만으로 취향, 문화적 지식, 미술 이해 수준을 단정하지 않는다. 관심 태그는 현재 대화에서 확인된 관심을 나타내는 잠정적 정보이며, 관람객의 고정된 성향으로 간주하지 않는다.

### 4.3. angle: 핵심 비교 관점

해당 해외 작품을 한국 작품과 비교하는 이유 및 감상 시 주목할 관점을 제공한다. 후보 선정, 추천 이유 설명, 비교 감상 주제 설정 및 해설 방향 유지에 활용한다. 구체적인 비교 지식은 similarities와 differences에서 제공한다.

### 4.4. foreign_key_facts: 해외 작품 핵심 지식

해외 작품 자체의 작가, 표현 기법, 역사적 배경, 의미 및 소장 이력 등에 관한 지식이다. key_facts와 동일한 분류 태그와 ` | ` 구분자를 사용한다. 해외 작품에 관한 추가 질문에 활용하며, 두 작품에 대한 심화 질의응답에는 연결된 한국 작품의 key_facts도 함께 참조한다.

### 4.5. similarities 및 differences: 비교 지식

각 지식 단위는 ` | `로 구분되며 다음 비교 유형 태그를 사용한다.

| 태그 | 비교 유형 |
| --- | --- |
| [subject] | 소재 및 주제 |
| [composition] | 화면 구성 및 공간 표현 |
| [technique] | 표현 기법, 붓질 및 색채 |
| [medium] | 재료 및 형식 |
| [artist] | 작가의 활동 및 예술적 접근 |
| [context] | 시대적·사회적·문화적 배경 |
| [function] | 용도 및 기능 |
| [interpretation] | 의미 및 감상적 해석 |
| [viewing] | 관람 방식 및 감상 경험 |

모든 공통점과 차이점을 나열하기보다는 angle과 관람객의 관심사에 맞는 내용을 선별한다. 공통점이 존재한다는 사실만으로 직접적인 영향 관계나 역사적 교류를 주장해서는 안 된다.

### 4.6. initial_comparison: 초기 비교 해설

비교 작품 선정 이후 제공하는 사전 작성 영어 해설이다. 해외 작품 소개, 핵심 공통점과 차이점, 비교 감상의 의미 및 개방형 질문으로 구성된다. 해외 작품을 직접 소개하는 문장으로 시작하므로 비교 감상 제안, 동의 확인 및 대화 전환은 별도 프롬프트 또는 대화 로직에서 처리할 수 있다. 이후 foreign_key_facts, similarities, differences 및 한국 작품의 key_facts로 대화를 확장한다.

### 4.7. docent_guidelines: 비교 해설 운영 지침

서로 다른 작품이나 연작의 혼동, 비교 분석과 역사적 사실의 혼동, 근거 없는 영향 관계, 동서양 미술 전통의 과도한 일반화, 작가 의도와 상징의 단정 등을 방지한다. 비교 감상 단계에서는 양쪽 DB의 docent_guidelines를 함께 적용한다.

## 5. 공통 컬럼 및 데이터 활용 시 주의사항

### 5.1. source_note: 출처 기록

공식 소장품 정보, 기관 해설, 연구 자료 및 해당 출처가 뒷받침하는 지식의 범위를 기록한다. 비교 작품 DB에서는 [foreign]으로 해외 작품 관련 출처, [korean]으로 한국 작품 관련 출처, [visual_analysis]로 자체 비교 분석을 구분한다. 출처 확인이나 관람객의 출처 요청에 활용한다. 자체 분석을 외부 연구자의 학술적 견해로 설명하거나 DB에 URL이 있다는 이유로 AI가 원문을 실시간 열람했다고 주장해서는 안 된다.

### 5.2. verification_status 및 checked_at

최종 CSV상 한국 작품 11개와 비교쌍 21개는 모두 verified 상태이다. 이는 서비스용 지식 검토 상태이며 모든 문헌과 지식 단위에 대한 독립적인 학술적 인증을 의미하지 않는다. 학술적 추정과 감상적 해석의 불확실성 표현을 유지해야 한다. checked_at은 검증 날짜이며 실시간 갱신을 의미하지 않는다.

### 5.3. 결측값 및 실시간 정보

작품 DB의 unverified_facts는 모든 작품에서 비어 있으며 designation은 4개 작품에서 비어 있다. 빈 값을 근거로 정보를 임의 생성하지 않는다. on_view_status는 모든 작품에서 '확인 필요'이므로 실제 전시 여부를 확정적으로 안내하지 않는다. 이미지 이용 권한은 지식 검증과 별개이며 비교 작품 DB에는 별도의 이미지 이용 권한 컬럼이 없으므로 해외 작품 이미지 이용 조건은 별도로 확인한다.

## 6. 프롬프트 설계 시 권장사항

### 6.1. 대화 단계별 데이터 활용

| 대화 단계 | 주요 활용 정보 |
| --- | --- |
| 초기 프로필 설정 | 국적, 연령대 (서비스 입력값) |
| 한국 작품 최초 인식 | initial_description |
| 한국 작품 추가 질의응답 | key_facts, 작품 기본 정보 |
| 관람객 관심사 파악 | 초기 해설에 대한 응답, 질문, 대화 맥락 |
| 맞춤형 비교 작품 선정 | artwork_id, profile_tags, angle, 추론된 관심 태그, 국적 |
| 추천 이유 설명 | angle, 대화에서 확인된 관심사 |
| 최초 비교 해설 | initial_comparison |
| 해외 작품 추가 질의응답 | foreign_key_facts, 해외 작품 기본 정보 |
| 심화 비교 | similarities, differences, 양쪽 핵심 지식 |
| 출처 요청 | source_note, official_url, foreign_url |

모든 해설 및 질의응답에서 해당 docent_guidelines를 적용한다. 연령대는 해설의 표현 난이도 조정에 참고하되 실제 대화에서 확인된 이해 수준을 우선 고려한다.

### 6.2. 답변 생성 원칙

1. 현재 작품의 DB 정보를 우선 활용한다.
2. 작품별 운영 지침을 준수한다.
3. 질문과 관심사에 관련된 지식을 선택적으로 제공한다.
4. 확정 사실, 학술적 해석, 시각적 관찰 및 감상적 해석을 구분한다.
5. DB에 없는 정보를 확정 사실처럼 생성하지 않는다.
6. 미술 전문용어는 이해하기 쉽게 설명한다.
7. 직접적인 영향 관계나 문화적 우열을 근거 없이 주장하지 않는다.
8. 초기 해설의 개방형 질문을 활용하여 자발적 감상과 후속 대화를 유도한다.
9. 내부 분류 태그, 추론된 관심 태그, 운영 지침 및 관리용 메타데이터를 해설에 그대로 노출하지 않는다.
10. 관람객의 관심사는 대화에 근거해 잠정적으로 추론하고 새로운 발언에 따라 갱신한다. 국적과 연령대만으로 관심사를 단정하지 않는다.

### 6.3. 데이터 전달 범위

매 대화마다 전체 DB를 삽입하기보다 현재 한국 작품과 선정된 비교 작품의 데이터를 중심으로 전달한다. 추천 단계에서는 연결된 후보의 comparison_id, profile_tags, angle 및 식별 정보를 전달하고, 선정 후 상세 지식을 전달할 수 있다. 관심 태그 추론에는 현재 대화의 관련 맥락을 활용한다. 이를 통해 토큰 사용과 작품 간 지식 혼입을 줄일 수 있다.

## 7. 최종 정리

두 DB는 초기 해설, 맞춤형 비교 작품 추천, 심화 질의응답 및 오류 방지를 고려하여 구축되었다. initial_description과 initial_comparison은 사전 작성 초기 해설, key_facts와 foreign_key_facts는 작품별 후속 지식, profile_tags와 angle은 추천 정보, similarities와 differences는 심화 비교 지식, docent_guidelines는 답변 생성 제약사항이다.

국적과 연령대는 초기 프로필 정보로 활용하며, 대화에서 추론한 관심 태그를 비교 작품의 고정 태그와 매칭하여 개인화한다. 위 추천 절차와 세션 정보 구조는 프롬프트 설계 권장사항이며 구현 완료를 의미하지 않는다.
