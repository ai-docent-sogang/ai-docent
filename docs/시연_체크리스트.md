# 시연 운영 체크리스트 (BE2 작성 예정)

담당: BE2. [역할 가이드 4장](역할_가이드.md)의 11/26–12/1 "시연 운영 준비"를 여기에 씁니다. 다른 팀원이 이 문서만 보고 서버를 켤 수 있어야 합니다.

채울 항목:
- 준비물: 노트북, 충전기, 핫스팟, 폰·글라스, 이어폰
- 켜는 순서: `.env` 확인 → 서버 실행 → Cloudflare 터널 → 폰에서 접속 확인
- 장애 시 대처: 터널 끊김, Gemini 오류, 인식 실패, 소리 안 남
- 대체 시연: 폰 모드, 사전 녹화 영상

## 시연할 때마다 기록할 것 (FE1 요청)

11/4 시연에서 어떤 모델 ID를 썼는지 아무 데도 남지 않았습니다. `GEMINI_MODEL`은 `.env`에 있고
`.env`는 커밋되지 않기 때문입니다. 그래서 11/4의 "체감 6~7초"를 나중에 측정한 값과 비교할 때
같은 모델이었는지 확인할 수 없었습니다. 다음 시연부터는 아래를 남깁니다.

| 항목 | 어떻게 얻는가 | 기록 |
| --- | --- | --- |
| 날짜·장소·시연자 | | 미기록 |
| 커밋 해시 | `git rev-parse --short HEAD` | 미기록 |
| `GEMINI_MODEL` | `.env`의 값. **키는 적지 않습니다** | 미기록 |
| 그 밖의 모델 설정 | `ASK_MOCK`, `ASK_FALLBACK_MODELS`, `LIVE_MODEL` 중 설정된 것 | 미기록 |
| 쓴 경로 | `/api/turn`(녹음·사진) · `/api/ask`(텍스트) · Live 중 무엇 | 미기록 |
| 응답 시간 | 화면의 서버 ms와 total ms. 수동 측정이면 그렇게 표시 | 미기록 |
| 관람객 수·질문 수 | | 미기록 |

`.env`를 그대로 붙여넣지 않습니다. `GEMINI_API_KEY`가 함께 들어갑니다. 모델 ID만 적습니다.
한 줄로 확인하려면 이렇게 합니다(키는 출력되지 않습니다).

```bash
git rev-parse --short HEAD && grep -E '^(GEMINI_MODEL|ASK_MOCK|ASK_FALLBACK_MODELS|LIVE_MODEL)=' .env
```
