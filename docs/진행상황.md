# 진행 상황

팀원과 AI 코딩 도구(Claude Code 등)가 함께 보는 현황판이다. 작업을 마치면 맨 위 "최근 기록"에 한 줄을 추가하고, 아래 표의 상태를 고친다. 일정과 목표는 [개발계획서](개발계획서.md) 8장을 따른다.

## 최근 기록

새 기록을 맨 위에 쓴다. 형식: `- 날짜 · 이름 · 한 일 (관련 PR·파일)`

- 2026-11-11 · 도혁 · Live API 전환 검토 중 코드로 확인 가능한 부분 확인. Live에 **음성**을 넣어도 받아쓰기 정확하고 `key_facts`로 답한다(엉뚱한 작품 질문도 걸러냄). 폰→우리 서버→Gemini WebSocket 중계 스파이크로 **말 끝난 뒤 첫 음성 950ms** 측정 — `/api/ask` 7.9초의 1/8. 아이폰 AudioWorklet 마이크 전송·생 PCM 재생·세션 15분 제한 처리는 미확인·미구현 (`docs/FE1_Live_검토.md`, `tools/probe_live_audio.py`, `tools/live_relay_spike.py`)
- 2026-11-11 · 도혁 · `/api/ask` 실제 응답 시간 측정(BE1과 같은 질문 10개, 실제 Gemini). 서버 시간 중앙값 **7.9초**, 왕복과의 차이는 15ms 이하 — 느린 곳은 모델이고 전송량·우리 코드가 아니다. 텍스트 전용이어도 `/api/turn`(8.1초)보다 빠르지 않다. 자료 없는 질문 3개는 모두 모른다고 답했다 (`docs/FE1_응답시간_측정.md`, `data/eval/ask_latency.csv`)
- 2026-11-11 · 도혁 · 브라우저 음성 인식(STT) 추가(`static/stt.js`). 말하면 질문 입력창에 글자가 들어가고, 지원하지 않거나 마이크가 막히면 글 입력으로 안내한다. 소리는 브라우저 회사 서버(아이폰은 Apple)로 가므로 외부 전송이다 — 시연 전 팀 공유 필요. 모의 테스트로 오류 안내가 "못 알아들었다"로 덮이는 문제와 오류 후 버튼이 멈추는 문제를 찾아 고침. **아이폰 실기기 시험은 미실행** (`static/stt.js`, `docs/FE1_아이폰_시험.md` A01~A09)
- 2026-11-11 · 도혁 · 웹앱을 `/api/ask`에 연결. 작품을 고르고 질문을 보내면 답변을 말풍선에 쓰고 음성으로 읽어 준다. `status`·서버 시간·왕복 시간·출처 링크 표시. 기존 `/api/turn` 흐름은 그대로 둠. 서버 주소와 작품 목록은 `static/config.js`로 분리(BE1과 합의되면 이 파일만 고친다). 확인: `node tests/test_ask.mjs`, `node tests/test_app_ask.mjs`, 로컬 서버 `ASK_MOCK=1` (`static/config.js`, `static/api.js`, `static/app.js`, `tests/`)
- 2026-11-11 · 도혁 · PR #5 머지. `origin/main`에서 서버 기동과 작품 11점 로드 확인
- 2026-11-11 · 도혁 · 머지된 `main`에서 서버가 켜지지 않던 문제 고침: Excel이 저장한 CSV의 BOM 때문에 `load_artworks()`가 `KeyError: 'artwork_id'`로 죽었다. `server/content.py`를 `utf-8-sig`로 읽게 바꿈(BE2 담당 파일, 한 글자 수정). 확인: 서버 임포트 성공, 작품 11점·비교쌍 7건 로드, `ASK_MOCK=1`로 `/api/ask` 정상·`no_artwork`·400 응답 확인 (`server/content.py`)
- 2026-11-11 · 도혁 · Codex 작업 인계 확인, GitHub 변동사항 점검(PR #3 FE3 콘텐츠, PR #4 BE1 `/api/ask` 머지)과 이 문서 반영. 브랜치를 `origin/main`에 맞춤 (`docs/Claude_인계.md`, `docs/진행상황.md`)
- 2026-11-11 · 도혁 · 아이폰 Safari 재시험 사용자 보고: 음성 테스트·자동 답변·다시 듣기 모두 정상. 음성 질문이 글자로 표시되는 것도 확인(현재는 서버의 Gemini 받아쓰기이며 브라우저 STT 검증은 아님). 지연 재측정과 STT·TTS 비교표 기록은 아직 (`static/`, `docs/FE1_아이폰_시험.md`)
- 2026-11-11 · 인우(BE1) · 텍스트 질문·답변 API `POST /api/ask` 추가. 작품 ID + 질문 → 답변, `status`(ok·mock·no_artwork·error)·`latency_ms`·`source_url` 반환, `ASK_MOCK=1` 임시 답변, 예비 모델 순서 처리. 실제 Gemini 답변 품질과 응답 시간은 미측정 (PR #4, `server/ask.py`, `docs/api.md`)
- 2026-11-09 · 예원(FE3) · 콘텐츠 DB 1차 검토 반영: `artworks.csv` 11점·`comparisons.csv` 7건 모두 `verified`, `comparison_extended.csv`와 `data/kb/emuseum_kb.jsonl` 추가 (PR #3)
- 2026-11-09 · 도혁 · 사용자 시연 보고: 체감 응답 약 6~7초(수동 추정, 표본 수·측정 구간 미확인), 인식은 정성적으로 양호. 카카오톡에서는 음성이 들리나 Safari·Google에서는 들리지 않음. 음성 초기화 순서 수정, 직접 음성 테스트·재생 오류 표시·답변 다시 듣기 추가. 실제 아이폰 재시험 필요 (`static/`)
- 2026-11-09 · 도혁 · FE1 아이폰 시험 절차와 STT·TTS 비교 기록표 준비. 실제 기기 시험과 음성 선택은 미실행 (`docs/FE1_아이폰_시험.md`, `docs/FE1_음성_비교.md`)
- 2026-11-05 · 도혁 · 역할 가이드를 11/4 결정(웹앱 우선, 가리키기, YOLO·임베딩 인식, STT·TTS 선택)으로 바꾸고 개발계획서 반영 (`docs/역할_가이드.md`, `docs/개발계획서.md`)
