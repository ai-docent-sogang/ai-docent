# AI 도슨트 (AIVY) 멘토 개요

기준일 2026-11-24. 숫자는 저장소 문서와 `data/`에 있는 값만 썼다.

## 목표

외국인 관람객이 국립중앙박물관 조선 회화 앞에서 폰 카메라로 그림을 비추고 영어로 물으면, 도슨트가 작품을 알아보고 관람객이 아는 외국 그림과 비교해 음성으로 답한다. 12/1 시연은 서화실 촬영이다.

## 개발계획서와 달라진 점

- 대화는 요청·응답 대신 Gemini Live 실시간 음성(`WS /ws/live`)을 본선으로 했다. `POST /api/turn`은 Live가 실패할 때의 안전망이다.
- 작품 인식은 YOLO 탐지와 임베딩 검색 대신 Live 모델이 사진을 보고 고른다. 모르면 `unknown`이고, 기준 이미지 검색은 켜면 보조로만 쓴다(기본 꺼짐).
- 가리키기(MediaPipe)와 YOLO는 11/18에 하지 않기로 했다. 별도 결정 문서는 없고 `docs/결정사항.md`에 적었다.

## 12/1 성공 기준과 현재 상태

| 기준 | 현재 |
| --- | --- |
| 작품 10~15점 인식 | 작품 11점 등록(모두 `verified`). 인식 정확도는 11점 전체로 재지 않았다. 11/17 측정은 3점·9장에서 8/9 |
| 작품당 검증된 비교 1~3점 | 비교쌍 20건 모두 `verified`(`data/comparisons.csv`). 11점 모두 1건 이상, 최대 4건(강산무진도) |
| 영어 음성 응답 지연 | 11/24 팀 리허설 첫 소리까지 중앙값 1.5초(n=15, 7분 1회). 측정 오류로 뺀 4턴은 원인 미확인 |
| 콘텐츠와 어긋나는 사실 진술 0건 | 미측정. 고정 질문 세트(`data/eval/questions.csv`)가 비어 있다 |

## 실행

```bash
uv sync
cp .env.example .env      # GEMINI_API_KEY, GEMINI_MODEL, LIVE_MODEL을 채운다
uv run uvicorn server.app:app --host 0.0.0.0 --port 8000
```

아이폰은 HTTPS에서만 카메라와 마이크를 연다. `cloudflared tunnel --url http://localhost:8000`을 쓴다. 자세한 절차는 `README.md`.

## 운영 화면(/admin) 확인

서버를 켠 노트북 브라우저에서 `http://localhost:8000/admin`을 연다. 인증이 없어서 로컬에서만 연다.

- 탭 세 개: 대시보드(관람 수·질문 비율·응답 시간 등), 질문 라벨, 작품 켜기/끄기.
- 숫자는 `logs/`의 관람 기록에서 계산한다. 관람 기록은 기본이 꺼져 있다. `.env`에 `LIVE_VISIT_LOG=team`을 켜고 서버를 다시 켠 뒤 폰으로 관람을 한 번 하면 쌓인다. 기록이 없으면 화면이 비어 있다.
- 기록에는 사진·음성·질문 원문이 없고 횟수·라벨·지연 같은 수치만 남는다.
- 작품 켜기/끄기는 메모리에만 남아 서버를 다시 켜면 처음 상태로 돌아온다. 끈 작품은 인식 후보에서 빠진다.
- 집계 방법과 API 형식은 `docs/api.md`의 운영 절에 있다.

## 글라스 SDK가 붙는 곳

`WS /ws/live`에 붙는다. 마이크 소리(16kHz PCM16)와 카메라 JPEG를 보내고 24kHz PCM16 음성을 받는다. 메시지 형식의 기준은 `docs/api.md`, 글라스 안내는 `glasses/README.md`. 글라스 연동 자체는 12/1 범위 밖이다.

## 알려진 한계

- `/admin`과 작품 켜기/끄기 API에 인증이 없다. 관내 로컬에서만 연다.
- `/api/turn`에 입력 크기 제한이 없다.
- Gemini 키가 없으면 서버는 켜지지만 첫 질문에서 500이 난다.
- 서화실 실제 전시 여부(`on_view_status`)는 11점 모두 확인 필요다.
- 기준 이미지 검색(인식 보조)의 정확도는 재지 않았다.
- `LIVE_FACTS=per_question`(기본)은 `per_artwork`보다 질문당 약 1초 느리다고 코드 주석에 적혀 있다(다시 재지 않았다).
- 시연 데이터는 팀원 역할극이다. 실제 관람객 행동으로 일반화하지 않는다.
