# 관람 분석 측정 계획

담당: FE1 김도혁. 개정일: 2026-11-15. 상태: 인터뷰 결정 반영, 실측 수집 기능은 미구현.

목표는 카메라 인식 기록으로 작품별 체류·관람 순서·재방문과 그 과정의 질문을 파악하는 것이다. 담당자가 어느 작품의 이용 양상과 해설을 추가 점검할지 판단하도록 돕는다. 콘텐츠 공백 진단은 보조 목적이다.

발표의 주 자료는 **모의 데이터**다. 가능하면 팀원 촬영·리허설 실측을 별도로 추가한다. 두 출처는 합산하지 않는다. 팀원 실측도 일반 관람객의 행동으로 일반화하지 않는다.

## 1. 인터뷰에서 확정한 범위

| 항목 | 결정 |
| --- | --- |
| 측정의 출발점 | 앱에서 고른 작품이 아니라 카메라의 작품 인식 결과 |
| 체류 인정 | 같은 작품이 일정 시간 이상 지속해서 인식된 경우 |
| 인식 끊김 | 짧은 공백은 유예 시간 안에 같은 작품이 돌아오면 같은 체류로 연결 |
| 작품 전환 | 다른 작품도 지속 인식 기준을 충족해야 확정 |
| 재방문 | A → B → A의 마지막 A는 새 체류로 기록하고 재방문으로 표시 |
| 관람 맥락 | 세션 내 이전 작품과 순서를 기억해 요청 시 비교 대화에 활용 |
| 직접 측정하지 않는 것 | 실제 시선, 라벨 읽기, 이해도, 물리적 이동 경로, 혼잡도 |
| 실측 보관 | 분석 기록과 팀원 실패 질문 텍스트는 수집 시각부터 30일 후 삭제 |
| 질문 텍스트 | 안내받은 팀원의 실패 질문만 저장. 실제 관람객은 박물관 협의 전 미저장 |
| 완료 산출물 | 이 계획과 [모의 보고서](FE1_관람분석_모의보고서.md). 운영 앱 기능 구현은 이번 범위 밖 |

국적·연령·언어별 분석과 운영자 대시보드는 이번 범위에 추가하지 않는다. 11/14의 `dohyeok/fe1-visit-analytics` 프로토타입 폐기 결정을 유지한다.

## 2. 조사 자료 1~4번의 반영

사용자가 지정한 범위는 근거 조사 문서의 **Details 1~4**다. Recommendations 1~4를 모두 채택한 것은 아니다.

| 조사 범주 | 이번 측정과 활용 | 해석의 한계 |
| --- | --- | --- |
| 1. 체류·주목 | 작품별 지속 인식 세션 비율, 체류 횟수·시간. 오래 또는 반복해서 잡힌 작품 점검 | 표준 attracting power나 실제 시선의 주목도는 아님 |
| 2. 작품 관람·라벨 읽기 | 체류 구간에 해설 이용·질문을 연결. 질문 유형을 보고 설명 보완 여부 검토 | 라벨 읽기는 측정 불가. 질문 증가가 관심인지 혼란인지 단정 불가 |
| 3. 동선·순서·혼잡도 | 인식 기반 관람 순서, 전환 쌍, 재방문 | 실제 이동 궤적·혼잡도는 측정 불가 |
| 4. 질문 내용·유형 | 체류 중 질문 유형·자료 부족·오류, 재방문 비교 질문 | 응답 성공은 정답 보장이 아님. 재방문만으로 비교 의도를 추정하지 않음 |

측정값의 이름은 **카메라 인식 기반 체류·주목 대리 지표**로 통일한다. 앱 화면을 연 시간과 구분한다. 앱 이용자 중 카메라를 든 사람만 기록되며, 카메라를 내리고 감상하면 누락된다. 여러 작품이 잡혀도 인식기가 주 대상으로 정한 한 작품만 측정한다.

## 3. 체류와 전환 판정

### 시간 기준

- `T`: 체류·전환을 인정하는 최소 지속 인식 시간.
- `G`: 같은 체류로 연결할 수 있는 인식 공백의 최대 시간.
- `H`: 정상적인 인식 결과 사이의 최대 간격. 결과가 없으면 마지막 작품을 계속 본 것으로 세지 않는다.
- 모의 예시만 `T=5초`, `G=4초`, `H=1초`를 사용한다. 운영 기준이나 인식 성능 실측값은 아니다.
- 실제 값은 BE2의 인식 주기·품질과 현장 기록으로 보정한다. 판정 파라미터 버전을 남긴다.
- 프레임 취득 시점의 세션 경과 시간으로 계산한다. 서버 응답 도착 시각을 쓰지 않는다. 지연 결과는 취득 순서로 처리한다.
- BE2가 수용한 작품 ID만 유효하다. 낮은 확신·모호한 후보는 `unknown`, 처리 오류는 `error`로 구분한다. 코사인 점수를 확률로 해석하지 않는다.

### 판정 순서

1. A가 처음 인식되면 후보로 둔다. 간격이 H 이하인 같은 A 인식이 T 이상 이어져야 체류로 확정한다. 확정 전 공백이나 다른 후보가 나오면 후보 지속 시간을 다시 센다.
2. 확정 후 체류 시작은 그 연속 구간의 첫 인식 시점으로 기록한다.
3. A 중 unknown 또는 B가 나오면 A의 인식 시간 증가를 멈춘다. B가 T를 채우기 전에는 대화의 현재 작품을 B로 바꾸지 않는다.
4. B도 기준을 채우면 A를 종료하고 B를 새 체류로 확정한다. B의 시작은 B의 첫 지속 인식 시점이다. A와 겹치지 않는다.
5. B가 기준을 못 채우고 마지막 A 인식에서 G 이내에 A가 돌아오면 같은 A 체류로 연결한다. 짧은 B는 확정 관람 순서와 대화 이력에 넣지 않는다.
6. G가 지나도록 A가 돌아오지 않으면 A는 마지막 유효 인식 시점에 종료한다. 유예 만료 시각까지 시간을 늘리지 않는다.
7. 이후 A가 다시 T를 채우면 새 체류이며 재방문이다. 직전 작품이 같아도 긴 공백으로 분리되면 새 구간이지만, 같은 작품끼리는 작품 간 전환으로 세지 않는다.
8. 카메라 중단·백그라운드 전환·연결 종료·세션 종료 시 마지막 유효 인식까지 닫는다. 세션 간 이력은 연결하지 않는다.

### 연결된 구간과 인식 시간

같은 체류로 묶는 것과 공백을 관람 시간에 넣는 것은 별개다.

| 값 | 정의 |
| --- | --- |
| `span_s` | 첫 인식부터 마지막 인식까지 연결된 체류 구간 길이 |
| `recognized_s` | 같은 작품의 인접 유효 인식 중 H 이하인 간격의 합. unknown·다른 후보·결과 미수신 간격은 제외 |
| `gap_s` | span_s − recognized_s. 직접 인식으로 뒷받침되지 않는 시간 |

주 보고값은 recognized_s다. span_s와 gap_s를 병기한다. 마지막 프레임 뒤 시간을 임의로 더하지 않는다. 샘플 간격으로 생긴 경계 오차는 인식 주기와 함께 명시한다.

## 4. 세션 맥락과 질문 연결

대화용 메모리에 현재 작품, 순서 있는 체류 이력, 이미 본 작품 목록을 둔다. A → B → A는 세 체류다. 첫 A와 마지막 A를 합치지 않으며 마지막 A에서도 B를 본 맥락은 유지한다.

“아까 본 B와 비교해 줘”는 현재 A와 이전 B의 출처 있는 콘텐츠를 조회해 답한다. 유사점과 차이점을 함께 설명하고 영향 관계를 단정하지 않는다. 대상이 모호하면 되묻는다. 세션 종료 때 대화용 기억과 대화 원문은 폐기한다. 30일 분석 기록을 다음 관람의 개인화에 재사용하지 않는다.

질문은 발화 시작 시각의 확정 체류 ID를 기록한다. 인식 공백 중에는 연결을 보류하고, 사후 확정된 구간 안의 질문만 연결한다. 연결 불가 질문은 unassigned다. 질문 대상 `subject_artwork_id`와 비교 대상 `comparison_artwork_id`는 카메라 작품과 별도로 둔다. 응답 시점의 작품으로 과거 질문을 덮어쓰지 않는다.

질문 유형과 결과는 BE1 응답에서 받는다. FE1이 별도 정규식 분류기를 만들지 않는다. 결과는 answered·no_source·error·unknown으로 구분하며 미지원 필드는 unknown이다. no_source는 시스템의 자료 부족 보고이지 DB 공백의 확정 판정이 아니다. FE3가 질문과 DB를 검토해 콘텐츠 보강과 검색·지시문 수정을 구분한다. answered의 사실 정확성도 고정 평가 질문으로 별도 검수한다.

## 5. 지표 사전

집계 단위는 `source_kind × exhibition_version × parameter_version`이다. 대상 기간과 n을 명시한다. 비율은 분자·분모를 함께 쓰고 분모 0은 N/A다. visit 수는 사람 수가 아니다.

| 지표 | 계산·단위·제외 조건 |
| --- | --- |
| 작품별 지속 인식 세션 비율 | 해당 작품 확정 체류가 있는 고유 visit 수 ÷ 수집이 켜지고 관측 구간이 있는 전체 visit 수. 체류 0건 세션도 분모에 포함 |
| 체류 횟수 | 작품별 고유 dwell_id 수. 재방문도 별도 건수 |
| 인식 기반 체류 시간 | recognized_s 합계, 구간 단위 중앙값·평균. 구간 수와 gap_s 합계 병기 |
| 관람 순서 | visit 안의 확정 체류를 시작 시각 순으로 나열. 짧은 후보 제외 |
| 작품 간 전환 | 같은 visit 안에서 인접한 서로 다른 작품의 체류 쌍 건수 |
| 재방문 | 같은 visit에서 이미 체류한 작품에 다시 확정된 구간 수 |
| 질문 있는 체류 | 질문이 연결된 고유 dwell 수 ÷ 전체 dwell 수. 질문 수와 구분 |
| 질문·실패 | 연결된 question_id를 작품·유형·결과별 집계. unassigned 별도 표시 |
| 해설 연계 | 해설 시작·종료 이벤트를 받을 때만 집계. 자료가 없으면 미수집 |

작은 시연 표본에서도 기술통계는 계산할 수 있다. 실제 관람객의 대표값이나 인기 순위로 해석하지 않는다. 인식이 잘 되는 작품이 높은 값을 얻을 수 있으므로 작품별 인식 누락도 점검한다.

## 6. 저장 구조와 개인정보

실측 기본값은 수집 꺼짐이다. mock·team_rehearsal·team_filming·visitor를 source_kind로 구분한다. 작품 CSV와 별도 분석 저장소를 쓰고 실제 로그와 실패 질문 텍스트는 Git에 올리지 않는다.

| 기록 단위 | 최소 필드 |
| --- | --- |
| visit | 난수 visit_id, source_kind, 관측 시작·종료 경과 시간, exhibition_version, parameter_version, expires_at |
| recognition | 이벤트 ID, visit, 증가하는 seq, 프레임 취득 경과 시간, artwork_id 또는 unknown, 결과 상태, 인식 버전 |
| lifecycle | 카메라 켜기·끄기, 연결 중단, 세션 종료와 경과 시간 |
| question | question_id, visit, 발화 시작 경과 시간, dwell_id 또는 unassigned, 질문 대상·비교 대상, BE1 label·outcome |
| failed_question | 팀원 안내 확인, question_id, 실패 질문 텍스트, 수집 시각, expires_at. 접근 제한한 별도 저장 |
| 파생 체류 | dwell_id, visit, artwork_id, 시작·끝·확정 시각, recognized_s·gap_s, 재방문 여부, 판정 버전 |

원시 인식·질문·수명주기 이벤트에서 체류와 집계를 다시 만든다. 중복 ID는 한 번만 처리한다. 10분 단위 시각 버림은 체류 계산을 망가뜨리므로 적용하지 않는다. 경과 시간과 순서를 보존하고 달력 시각은 만료 관리에 한정한다. 공개 보고서에는 세션 상대 시각을 쓴다.

전시 회차·전시실은 확인된 메타데이터에 연결한다. 실제 전시 목록·위치를 모르면 확인 필요로 남긴다. 국적 대신 UI 언어를 수집하는 제안은 이번 인터뷰의 채택 범위가 아니다.

음성·프레임은 저장하지 않는다. 성공 질문 원문·답변 원문도 분석 저장소에 남기지 않는다. 팀원 실패 질문 텍스트 저장만 이번 인터뷰에서 승인한 예외다. `server/logs.py`와 회의록의 원문 미저장 기본 원칙은 일반 관람객에 계속 적용한다. 실제 관람객 수집·텍스트 저장은 박물관 협의와 안내 방식을 정하기 전 활성화하지 않는다.

30일 삭제는 원시 이벤트·파생 체류·실패 텍스트·내보낸 실측 파일에 적용한다. 발표에 남길 자료는 원문과 개별 방문 순서를 제거한 집계표다. 개별 시연 사례는 팀원 동의 범위만 사용한다. 삭제 실행·실패 감지도 구현 및 검증 대상이며 현재 구현됐다는 뜻은 아니다.

## 7. 현재 코드와 추가 작업

2026-11-15 작업 트리 확인 기준이다.

- `static/app.js`의 onRecordingStop·글 입력은 질문 시 captureFrame 한 장을 보낸다. 결과 사이의 시간을 연속 체류로 세면 안 된다.
- `server/recognition.py`는 후보 검색 모듈이며 서버 미연결 상태라고 명시한다. 반복 관측 결과 경로가 추가로 필요하다.
- `server/session.py`는 현재 작품·처음 본 작품 목록·최근 대화를 메모리에 둔다. 순서 있는 체류·재방문과 지속 인식 판정 연계는 추가 작업이다.
- `static/live_test.js`의 작품 선택은 시험용 입력이다. 카메라 인식 실측으로 취급하지 않는다.
- `server/logs.py`는 아직 구현되지 않은 자리다. 응답 지연·서비스 오류는 BE2, 체류·관람 집계는 FE1로 경계를 맞춘다.

| 합의 대상 | 필요한 계약 |
| --- | --- |
| BE2·FE1 | 관측 주기, 프레임 취득 시각·seq, 유효 ID·unknown·error, 카메라 중단. 반복 관측 없으면 실측 체류 미지원 |
| BE1·FE1 | question_id, 발화 시작 시각, 유형·자료 부족 코드, 질문 대상·비교 대상, 확정 관람 이력 전달 |
| BE1 | 지속 인식으로 확정한 현재 작품·이력을 대화에 사용. 모델이 보고한 한 번의 ID로 확정 이력을 덮어쓰지 않기 |
| FE3 | 라벨 의미·평가 질문·실패 텍스트 검토, 비교 설명 출처 검수 |

인식·분석 수집이 실패해도 음성 대화를 막지 않는다. 지속 인식이 미구현이면 실측 영역은 미수집으로 남긴다.

## 8. 근거의 사용 범위

[근거 조사 문서](<AI 도슨트 관람 분석 측정 계획 근거 조사_ 국립중앙박물관 조선회화 전시의 질문 로그 기반 콘텐츠 공백 진단.md>)의 Details 1~4를 반영했다. 조사 문서의 모든 문헌과 수치를 재검증한 것은 아니다. 다음 원자료를 직접 재확인했다.

- [Serrell, Paying More Attention to Paying Attention](https://informalscience.org/paying-more-attention-paying-attention/), 2010·2016 개정, 확인 2026-11-15. SRI는 전시 면적 ft²를 표본의 평균 총 관람 시간 분으로 나눈 값이다. %DV는 전시 요소의 절반을 넘게 멈춘 표본 관람객 비율이다. 우리 인식 시간을 이 이름으로 부르지 않는다.
- [Brooklyn Museum, Connecting with Curators](https://techblog.brooklynmuseum.org/index.html%40p%3D7432.html), 2015, 확인 2026-11-15. 질문 스니펫을 소장번호와 연결하고 큐레이터의 지식·검토를 연결한 사례다. 질문과 작품을 연결할 근거이며 카메라 체류 측정의 타당성 근거는 아니다.

attracting·holding power의 정확한 원문 정의는 확인 필요다. 기존 holding power 비율 정의를 확정값으로 쓰지 않는다. 서양 미술관의 평균 관람시간을 T로 가져오지 않는다. 모의 데이터로 해설·재배치의 효과를 주장하지 않는다.

## 9. 검증과 완료 기준

이번 완료 기준은 인터뷰 결정과 보고서의 지표가 일치하고, 예시 원자료에서 숫자가 재계산되는 것이다. [모의 입력](examples/visit_analytics_mock.json)은 이미 판정된 체류를 직접 만든 합성 자료다. `python3 tools/make_visit_analytics_mock_report.py`로 보고서를 재생성한다. 이 도구는 집계 예시이며 인식·체류 판정기를 구현하거나 검증하지 않는다.

실측 구현의 후속 합격 기준은 다음과 같다.

| 검증 사례 | 기대 결과 |
| --- | --- |
| A가 T 미만 | 체류 0건. 관측 세션 분모에는 포함 |
| A → G 이내 unknown → A | A 체류 1건. 공백은 recognized_s에서 제외 |
| A → 짧은 B → A, 전체 공백 G 이내 | B 체류·전환 0건. A 1건 |
| A → 기준 충족 B → 기준 충족 A | 체류 3건, 전환 2건, A 재방문 1건 |
| G 초과 중단 후 A 재인식 | A 체류 2건. 공백 미포함 |
| 프레임 미수신·카메라 꺼짐 | 마지막 작품의 시간을 계속 늘리지 않음 |
| 질문 중 전환·이전 작품 비교 요청 | 발화 구간과 질문 대상·비교 대상을 구분 |
| 중복·지연 결과·세션 종료 | 중복 집계 없음, 마지막 유효 시각에 종료, 세션 간 연결 없음 |
| 30일 만료·세션 종료 | 실측 저장물 삭제, 대화 메모리 즉시 폐기, 새 세션에서 과거 기억 조회 불가 |

가능하면 팀원 수기 정답과 인식 이벤트·체류 집계를 한 줄씩 대조한다. 인식 주기·시간 경계 오차·놓친 작품·잘못 전환한 작품을 별도 기록한다. 실측을 못 하면 미수집으로 표시한다.

남은 기술 합의는 T/G/H의 현장 보정, 반복 인식 인터페이스, BE1 라벨·코드, BE2 로그 경계다. 실제 관람객 수집과 텍스트 저장은 박물관 협의 항목으로 유지한다.
