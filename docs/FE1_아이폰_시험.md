# 아이폰에서 현재 웹앱 시험하기

담당: FE1 김도혁. 상태: 시험 전. 최종 완성 전에도 현재 v0로 실행한다.

## 시험 준비하기

1. [README](../README.md)의 준비와 실행 절차로 서버를 켠다. `.env`와 의존성은 새 작업 폴더에도 별도로 준비한다. 키를 기록표에 적지 않는다.
2. Cloudflare 터널의 HTTPS 주소를 아이폰 Safari에서 연다.
3. 이어폰을 연결하고 음량과 무음 모드를 확인한다.
4. 맥 Safari의 개발자용 메뉴에서 연결된 아이폰의 페이지를 선택한다. 메뉴가 없으면 각 기기의 웹 검사 설정을 확인한다.
5. 아래 환경 기록을 채운다. 실제 관람객 대신 시험자와 사용 조건이 확인된 작품 자료를 쓴다.

## 지연과 오류 기록하기

- 현재 화면의 total은 전송 시작부터 응답 수신까지다. 녹음 변환과 실제 음성 재생 시작은 포함하지 않는다.
- 체감 지연은 버튼에서 손을 뗀 순간부터 답의 첫 소리가 들린 순간까지로 기록한다. 녹음 종료 자동 감지가 붙으면 시작 기준을 다시 명시한다.
- 스톱워치로 재면 수동 측정이라고 표시한다. 현재 측정 도구가 없으면 미측정으로 남긴다.
- 시험 ID, 재현 순서, 예상 결과, 실제 결과, 정제한 오류 메시지를 남긴다. 키, 대화 원문, 음성, 프레임은 저장하지 않는다.
- 같은 조건으로 다시 시험할 때는 새 세션을 시작한다. 현재 웹앱에는 종료 기능이 없으므로 서버 재시작으로 기존 세션을 폐기하고 페이지를 새로 연다.

| 시험 ID | 체감 지연 ms | 측정 방법 | 화면 Gemini ms | 화면 total ms | 오류·재현 조건 |
| --- | --- | --- | --- | --- | --- |
| 미기록 | 미측정 | 미기록 | 미측정 | 미측정 | 미기록 |

가리키기와 여러 프레임 전송은 현재 미구현이다. FE2와 BE1 연동 후 시험 항목을 추가한다. STT·TTS 선택은 [비교 기록표](FE1_음성_비교.md)를 사용한다.
