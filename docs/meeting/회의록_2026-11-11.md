## 4. 합의 사항 (구현 시 따를 방향)

- **대화 API**: 초기 버전은 Gemini Live API 적용 → 프롬프트 개선 후 품질·오류 재평가
- **시연 범위**: 기존 **11점 작품** 기준으로 구현. 실제 전시장에 해당 작품이 있는지 확인 후 확정
- **비교 해설 UX**:
  - 처음부터 유명 작가를 고르게 하지 않음
  - 작품 기본 해설 → 관련 비교 작품을 먼저 제안 → 사용자가 관심 대상 선택
  - 무리한 비교·근거 없는 관계 설정 금지
- **개인화**:
  - 초기 설정에서 최소 **국적·연령대** 입력 (->국적 등에 맞춰 관심이 높을 법한 해외의 작품과 연결)
  - 언어, 설명 어조·어휘·말하기 속도를 사용자 특성에 맞춤
  - 입력 방식(선택형 vs 음성)은 UI 단계에서 결정
- **도슨트 운영 메모**: 당분간 CSV `source_notes` 컬럼에 유지, 시스템 프롬프트에서 참고. 문제 생기면 별도 컬럼 분리 재검토
- **사용자 / 기관 기능 분리**:
  - 관람객: 방문한 작품 요약 제공, 대화형으로 참여해 관람객의 흥미를 높임
  - 박물관: 체류 시간·질문 내용 등 집계 데이터 제공. 별도 화면보다 **데이터 수집·분석 구조 우선**
- **확장 연구**: 작품 DB(해외-국내 비교쌍) 자동 수집·생성, 국내외 작품 자동 매칭은 11/18 필수 범위 아님 → 병행 실험
